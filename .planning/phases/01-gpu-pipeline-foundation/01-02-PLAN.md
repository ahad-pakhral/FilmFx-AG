## Verification
1. Core shaders compile and link without artifacts on Adreno, Mali, and PowerVR targets.
2. The final image matches the input image visually (accounting for filmic roll-off), proving the linear/sRGB conversions are mathematically sound.
3. No banding is visible when applying heavy gradients or exposure pushes internally.

## Must Haves
- The shader compilation must occur before the user enters the main UI.
- The pipeline must process in the correct order (Linearize -> Process -> Tone Map -> Gamma).
