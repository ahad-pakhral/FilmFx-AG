# Plan 03-01: Oklab Split Toning Shader

## Goal
Implement a high-precision `SplitToningFilter` using the Oklab color space for natural perceptual grading.

## Proposed Changes

### [NEW] SplitToningFilter.kt
- **Shader**: 
    - `Linear RGB -> Oklab` conversion using matrix transforms.
    - **Blending**: Implement Soft Bell-Curve weighting for highlight/shadow distribution.
    - **Tinting**: Apply (a, b) shifts based on user-selected Hue/Sat for both ranges.
    - `Oklab -> Linear RGB` back-conversion.
- **Uniforms**:
    - `uHighlightHue`, `uHighlightSat`
    - `uShadowHue`, `uShadowSat`
    - `uBalance` (-1.0 to 1.0)
- **Position**: Place in the pipeline between `LinearizeFilter` and `ToneMapFilter`.

## Verification Plan

### Automated Verification
- GLSL compilation check.
- Verification of 16-bit texture compatibility.

### Manual Verification
- **Neutral Check**: Hue=0, Sat=0 results in no color shift.
- **Balance Test**: Shift Balance to +1.0; highlight tint should dominate the midtones.
- **Perceptual Test**: Inspect color shifts in skin tones to ensure Oklab provides natural transitions compared to RGB tinting.
