# Plan 03-02: Joystick UI & State Integration

## Goal
Provide an intuitive touch-based UI for controlling split toning parameters using 2D Joysticks.

## Proposed Changes

### [MODIFY] EditorScreen.kt
- **UI Logic**:
    - Build a `SplitToningControl` component containing two `JoystickPad` composables.
    - **Highlights Pad**: Controls `highlightHue` and `highlightSat`.
    - **Shadows Pad**: Controls `shadowHue` and `shadowSat`.
    - **Balance Slider**: Shared control for tint distribution.
- **State Management**:
    - Track 5 new floats: `hHue`, `hSat`, `sHue`, `sSat`, `balance`.
    - Map XY drag coordinates to Hue/Sat math.
- **GPU Integration**:
    - Add `SplitToningFilter` to the `GPUImageFilterGroup`.
    - Update uniforms in the `AndroidView.update` loop.

## Verification Plan

### Manual Verification
- **Joystick UX**: Confirm dragging the joystick pad updates the image in real-time.
- **Visual Feedback**: The joystick handle should visually stay at the touch point until released, returning to center if "Snap to Center" is desired (or staying for "Set and Forget" - user preference usually favors staying for grading).
- **Layout**: Ensure the UI fits comfortably on a standard screen size without obscuring the image too much.
